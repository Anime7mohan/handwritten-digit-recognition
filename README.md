# Handwritten Digit Recognition with Deep Learning

This project focuses on building a deep learning model using Convolutional Neural Networks (CNN) to recognize handwritten digits from the MNIST dataset. It also includes comparative analysis with a traditional Support Vector Machine (SVM) model.

## Project Overview

- *Goal:* Automatically classify handwritten digits (0–9)
- *Dataset:* [MNIST dataset](https://www.kaggle.com/datasets/oddrationale/mnist-in-csv) (70,000 grayscale images of size 28x28)
- *Tech Stack:* Python, TensorFlow/Keras, scikit-learn, matplotlib, seaborn
